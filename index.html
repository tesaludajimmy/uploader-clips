Uploader Clips

Uploader Clips is a private desktop tool used by the creators of the podcast Delirios & Barbaries. It takes the short vertical clips we edit from our own episodes and sends them to our own TikTok account's inbox through the official TikTok Content Posting API (upload mode).

Nothing is published automatically. Each clip arrives as an inbox notification in the TikTok app, where we edit it, save it as a draft or post it ourselves.

The tool is not offered to the public and has no other users.
